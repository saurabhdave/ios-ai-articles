Swift Snippet of the Week

import SwiftUI @Observable final class FeedModel { var items: [String] = [] func append(_ s: String) { items.append(s) } } struct FeedView: View { @StateObject private var model = FeedModel() var body: some View { List(model.items, id: \.self) { Text($0) } } }

This pattern matters because it separates a single observable domain model from ephemeral view ownership, which helps avoid duplicate observers and spurious re-renders in scrolling lists.
